# 🚀 نظام إدارة وتوزيع محادثات Chatwoot الذكي (Chatwoot Smart Router)

نظام محلي متكامل ومستقل بنسبة 100% لإدارة وتوزيع محادثات Chatwoot التلقائي، مربوط مع نظام CRM لسحب الشيفتات ومطابقتها ومراقبة تأخيرات الرد.

---

## 📂 محتويات النظام:
1. **Backend:**
   - pp.py: سيرفر Flask ومحرك التوزيع التلقائي (PeriodicRouter) ونقاط الـ REST API.
   - database.py: محرك قاعدة البيانات SQLite (Agents, Settings, Chats Log).
   - crm_service.py: خدمة سحب ومزامنة شيفتات الـ CRM ومطابقة الأسماء.
   - 
outing.db: قاعدة بيانات SQLite الحية.
   - 
equirements.txt: متطلبات بايثون لتشغيل السيرفر.
2. **Frontend:**
   - src/: الكود المصدري لواجهة React + Vite (الصفحات، المكونات، دوال الـ API).
   - dist/: النسخة المبنية الجاهزة للتشغيل الفوري مع سيرفر Flask.
   - package.json: إعدادات ومكتبات واجهة المستخدم.
3. **أدوات التشغيل والتوثيق:**
   - تشغيل_النظام.bat: ملف التشغيل الفوري للنظام بنقرة واحدة.
   - Chatwoot_CRM_Users_Mapping.xlsx: شيت إكسيل يوثق مطابقة الموظفين بين شات ووت والـ CRM.
   - برومبت_استئناف_المشروع.txt: الذاكرة البرمجية الكاملة للمشروع لاستئناف التطوير في أي وقت.

---

## ⚡ طريقة التشغيل:
1. انقر نقراً مزدوجاً على ملف: **تشغيل_النظام.bat**.
2. افتح المتصفح على الرابط: **http://localhost:5005**.

---
